## How to Use

### Installation
```bash
pip install -r requirements.txt
python timer.py
```

### First Time
1. Select training preset
2. (Optional) Load music from USB
3. Press START

### Settings Auto-Save
- Work/rest times are saved
- Selected preset is remembered
- Music folder is remembered
- Volume is saved
- Window position is saved

### View Statistics
- Click "📊 Stats" button
- See total sessions, time, rounds
- Click "Exportă" to save report

### Use Keyboard Shortcuts
- Press "⌨️ Help" button to see all commands
- Number keys 1-5 to load presets
- Space to start/pause
- R to reset
